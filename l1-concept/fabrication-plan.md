# Fabrication Plan

## Feasibility

Feasible as an L1 concept if the fixture is treated as a system around a certified universal testing machine, not as a home-built load frame. The safest first path is to buy or borrow rated grips and fabricate only simple adapters after the load chain is fully documented.

## Primary Route

1. Record machine, load cell, controller, guard, and grip ratings.
2. Choose the first specimen family and estimate peak tensile load from material strength and reduced-section area.
3. Select purchased rated grips with capacity above the predicted peak load and below the frame/load-cell limits.
4. Draft adapter drawings only where a rated grip does not directly interface with the machine.
5. Machine adapters from traceable metal stock, keeping all load-bearing features inspectable.
6. Add a shield or use the manufacturer's enclosure before any powered pull.
7. Run a dry setup check with no specimen, then a low-load proof check under supervision before any fracture test.

## Fallback Route

If rated grips are unavailable, pause custom fabrication and convert the packet into a drawing brief for a qualified shop or test-lab accessory vendor. Do not improvise jaw geometry for a live tensile pull.

## Go/No-Go Checks

- Go only if every load-chain component has a known rating or a signed engineering calculation.
- Go only if the predicted peak load stays below the controlling component rating with documented margin.
- Go only if the shield/guard plan is installed before a fracture test.
- No-go if the specimen can bend, slip, or cock visibly during preload.
- No-go if any adapter has unknown material, unknown heat treatment, damaged threads, or uninspected fasteners.

## Prep Actions

- Create a P1 drawing brief for custom adapters after machine/grip selection.
- Capture photos of the target machine interfaces.
- Add a load-estimate worksheet for each candidate material and coupon diameter.
- Add a signoff line for the machine owner or shop safety lead.
